# The Complex

A first-person multiplayer social deduction game built with **Unity 6**.

## About

**The Complex** is a multiplayer mystery game where players are trapped inside a mysterious facility. Every player is assigned a hidden role and must work together—or against each other—to survive, complete objectives, uncover the truth, and identify the culprit.

The project is currently in active development.

## Current Features

- First-person player controller
- Character movement
- Sprint
- Jump
- Ground detection
- Raycast-based interaction system
- Modular interaction interface
- Interaction prompt UI

## Planned Features

- Interactive doors
- Keycards and locked areas
- Inventory system
- Task and objective system
- Evidence collection
- CCTV system
- Role-based gameplay
- Discussion and voting
- Multiplayer networking
- Voice chat integration
- Dynamic maps and events

## Built With

- Unity 6
- C#
- Unity Input System
